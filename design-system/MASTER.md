# Color Shift visual system

The Endless MVP uses a calm, compact dark interface for all ages. The deep navy `#071426` remains visible as the base; surfaces use `#10233A` and `#162C45`. Primary text is `#F4F7FB`, muted text is `#AAB8CA`, and focus outlines use `#DCE8F7`.

The match palette is coral `#D96B68`, sky `#67A9C9`, mint `#71B797`, sun `#D8B65F`, and plum `#9A729E`. Color never carries state alone: labels, marks, borders, and accessibility state provide the same meaning.

Spacing follows 4, 8, 16, 24, and 32 point steps. Controls use a 14 point radius, tiles 16, and bottom sheets 28. Interactive targets are at least 48×48 points, with visible pressed, focused, and disabled states.

Manrope is the sole interface family. Russian copy is concise and friendly. Layouts avoid flashy gradients, decorative motion, and visual clutter. Reduced motion preserves clear state changes without scale-heavy effects.

Home hierarchy is title, player progress card, then actions. Player, mode, profile, settings, and confirmation surfaces are focused components. Endless is the only enabled mode; Time Attack and Demining remain visible, disabled, and labelled “Скоро”. Avatar editing is visible but unavailable in the MVP.
